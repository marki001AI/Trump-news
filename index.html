Einstellungen

Mit Key übersetzt Claude Haiku – deutlich treffender bei politischen Begriffen. Ohne Key läuft es über den kostenlosen MyMemory-Dienst mit Tageslimit. Der Key wird nur auf diesem Gerät gespeichert.

Ohne Key läuft die Interviews-Spalte nur über Nachrichtenquellen. Mit Key kommen Pressekonferenzen und Interview-Videos direkt aus der YouTube-Suche. Den Key in der Google Cloud Console auf deine Pages-Domain als HTTP-Referrer beschränken.

Eine URL pro Zeile. Endet die URL auf #social, landen die Treffer in der Social-Spalte.
